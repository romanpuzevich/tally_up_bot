# tally_up_bot

Telegram-бот для личного учёта расходов в рублях. Расход попадает в отчёт после нажатия «Записать». Каждый пользователь видит свой бюджет.

## Локальный запуск

Понадобятся [uv](https://docs.astral.sh/uv/getting-started/installation/) и токен бота. Получите токен командой `/newbot` в личном чате с [@BotFather](https://t.me/BotFather). Из корня репозитория выполните команды ниже.

```sh
uv python install 3.13
uv sync --locked
cp .env.example .env
```

Вставьте токен в строку `BOT_TOKEN=` файла `.env`. Значения из окружения процесса имеют приоритет над файлом. По умолчанию `DATABASE_URL=sqlite+aiosqlite:///data/bot.db`, а `APP_TIMEZONE=Europe/Moscow`. Часовой пояс можно заменить другим именем IANA.

```sh
uv run pytest
uv run python -m bot
```

Тестам достаточно установленных зависимостей. Они используют временные SQLite-файлы и подменяют отправку запросов в Telegram. Токен нужен только для запуска настоящего бота.

Бот работает одним процессом через long polling. Достаточно исходящего HTTPS-соединения с Telegram. При первом запуске бот создаст каталог и таблицы. Для остановки нажмите Ctrl+C. При следующем запуске с тем же файлом базы сохранятся и черновики, и подтверждённые расходы.

## Проверка в личном чате

1. Отправьте `/start`, затем `349,90 кофе`. Появится черновик «349,90 ₽ · Кафе · кофе». Бот также принимает `350 кофе` и `349.90 кофе`.
2. Нажмите «Категория», выберите «Продукты» и нажмите «Записать». Откройте `/today` и проверьте сумму, новую категорию и итог.
3. Отправьте `100 метро` и нажмите «Отмена». Итог за сегодня должен остаться прежним.
4. Перезапустите процесс и повторите `/today`. Откройте бота со второго аккаунта и проверьте его отдельный бюджет.

Суммы хранятся целыми копейками. Дата расхода определяется моментом подтверждения в UTC. Отчёт выбирает записи от местной полуночи включительно до следующей полуночи исключительно.
